# Rock Paper Scissors 🎮

A simple console-based Rock Paper Scissors game developed using C++.

## About
This game allows a player to compete against the computer. Both choose Rock, Paper, or Scissors, and the winner of each round earns one point. The first to reach 3 points wins the game.

## Features
- Play against the computer.
- Random computer choices.
- Automatic winner detection.
- Score tracking.
- First-to-3-points game system.

## Technologies
- C++
- Standard C++ Library

## How to Run

Compile:

```bash
g++ main.cpp -o game
```

Run:

```bash
./game
```
